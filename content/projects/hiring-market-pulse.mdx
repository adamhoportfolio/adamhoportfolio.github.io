## Question

What do three years of startup hiring posts say about remote work, pay transparency, and in-demand skills? And how can a reader know the numbers are right?

## Pipeline Areas

1. Ingestion from the Hacker News and BLS APIs, with data contracts and a quarantine for rejected records
2. Rules-based extraction of work mode, salary, role, seniority, and tech stack from free text
3. Load to Databricks (Unity Catalog volume to Delta tables)
4. dbt staging and mart models with 52 data tests
5. Gated publishing: the dashboard updates only if every hard test passes; otherwise a GitHub issue opens
6. Streamlit dashboard with a built-in data-quality panel
7. dbt docs site with lineage and per-column tests

## Quality

- **Data tests:** uniqueness, relationships, accepted values, salary rules, no missing months, freshness, schema drift, and a cross-source divergence warning
- **Mutation check:** the data is corrupted 11 different ways, and each matching test must fail (11/11)
- **Accuracy audit:** the extractor is scored against 50 hand-checked posts. It found a definition bug that understated remote work by about 5 points; work-mode accuracy went from 91% to 98% and seniority from 70% to 91%
- **CI/CD:** the main branch is protected, so a change can't merge until lint, types, 90 unit tests, a dbt build with every data test, and 16 Playwright tests pass. After merge, the app and docs deploy automatically; a daily refresh publishes data only when tests pass; a smoke test checks the live site
- **In production:** the daily refresh failed twice in its first week (a warehouse quota, then a government API outage). Both times nothing bad was published and an issue opened automatically; the fixes and a blameless write-up followed the same day

## Findings (Nov 2023 to Sep 2026)

- Posts listing a salary rose from 13% to 31%
- Remote-friendly posts fell from 67% to 55%; onsite-only rose from 15% to 25%
- LLM/GenAI mentions nearly doubled, to 15% of posts
- HN post volume fell 6% while official Information-sector openings fell 35%, so HN is not a stand-in for the broader market
