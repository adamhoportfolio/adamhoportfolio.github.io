<Callout title="All data in this project is simulated">
This is a portfolio project built on a Spotify clone. It uses no real Spotify users or data, and it is not affiliated with Spotify. The results show the method, not real-world effects.
</Callout>

## Question

Does an interactive 3-choice "Next Recommended Songs" banner (Smart Queue) increase listening time without hurting retention or stability?

## Result

| Metric | Outcome |
|---|---|
| Primary OEC (listening minutes per user per week) | +26.6 min/user/week (+3.2%, p = 1.2e-5) |
| Expected effect at steady state | about +2.7% after novelty decay |
| Guardrails (retention, crash rate) | Passed |
| Recommendation | Launch with a 5% holdout |

## Design

- 14,420 simulated users over 28 days (398,080 rows)
- Power analysis: 7,210 users per variant
- Metrics defined up front: one OEC, guardrail, secondary, and diagnostic metrics
- Tests pre-registered before the data was generated
- Sample ratio mismatch (SRM) check before any hypothesis test
- Causal analysis with intent-to-treat (ITT) and complier average causal effect (CACE)

## Pipeline

1. Business question and metric definitions
2. Tracking plan
3. Power analysis and pre-registered tests
4. Data simulation
5. SRM check
6. BigQuery aggregation
7. Hypothesis testing
8. Mixpanel import and dashboard
9. Decision memo
